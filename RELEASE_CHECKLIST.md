# Release checklist

Status is evidence-driven. An unchecked item is not complete.

- [x] Author confirmed: Leonard van Hemert, no affiliation/ORCID supplied.
- [x] Ownership and MIT code/Lean + CC BY 4.0 paper/data confirmed.
- [x] Original research directory preserved; release copy separated.
- [x] Raw-derived evidence checks and exact rational correspondence run.
- [x] Fresh real encrypted two-process functional inference run.
- [x] General Lean targets build; principal theorem axioms inspected.
- [x] Manuscript compiled, bibliography/cross-references checked, PDF inspected.
- [x] Independent concrete findings resolved and verification boundaries recorded.
- [x] Clean extracted checkout validated; manifests finalized.
- [x] Dedicated GitHub repository pushed; required hosted checks successful.
- [x] Exactly one manual Zenodo draft created and actual DOI reserved.
- [x] Reserved DOI inserted; final PDF/metadata rebuilt and revalidated.
- [x] Final commit checked; immutable version tag and GitHub release created.
- [x] Exact tagged archive, paper and supplement uploaded with hashes.
- [ ] Zenodo record published; DOI, visibility, metadata and downloads verified.

The canonical final state is recorded in `docs/PUBLICATION.md` and the hosted
release. A reserved DOI is not a published DOI. Tags are never moved to conceal
corrections; published changes require a new version.
