# Approach registry

All routes were developed independently before synthesis; each note distinguishes
proved facts, executed experiments, author-reported results and untested ideas.

| Family | Decisive assumption / mechanism | Evidence / disposition |
|---|---|---|
| Real product-minimal factors | Real scalar circuit; constants/additions free | Theorem and archived inertia verified; not an FHE lower bound. |
| Terminal cyclic orientation | Only consumer is real scalar x dot(Ax); public Q | Primary implemented route; generic cyclic support optimum; encrypted broad sweep and HTTP confirmation. |
| Direct triangular contraction | Ordinary off-diagonal doubling | Mandatory strong baseline; frequently fastest baseline. |
| Dense spectral / sparse LDL squares | Public factors, stable completion of linear term | Packed baselines implemented;14 exact full affine certificates; measured. |
| Complex support-overlap LDL | Opposite signs; final client real projection; bounded factor growth | Implemented feature SIMD route; measured lower product/linear counts; loses low-batch total chain. |
| Feature / neuron layout selection | Batch capacity and client communication matter | Packed and feature layouts compared at same B128; full communication bytes counted. |
| BSGS / hoisting / rotation keys | Count total kernel cost, not rotations alone | Official kernels, ratios0–3, actual eval-key sizes and RSS. |
| Setup-horizon scheduling | Same public model/client key reused H times | Measured S+HT planner with key/RSS budgets; d32 direct vs BSGS tradeoff. |
| Key-memory streaming | Key lifetimes large enough to dominate | KeyMemRT verified as existing work; not claimed as new. Algebraic key elimination retained. |
| Polynomial approximation | Approximation allowed by application | Primary class is exact square, so no quality-changing approximation used. |
| Bootstrapping / low-rank refresh cuts | Deeper circuit needs refresh | Strong quadratic baseline already0 bootstraps. Reserve rank-cut construction in notes/poly_bootstrap.md is untested. |
| General compiler / AI configuration | Deterministic costs and actual execution needed | Orion/HEIR/FHE-Agent checked; new mechanism is a specific rewrite, not an LLM-search instruction. |
